    FireControl (Langmuir): load, adjust and cut on CrossFire, PRO and XR

    The free control software for Langmuir tables: loading G-code, scaling, dry run, run-from-here, pierce delay, and torch height control (THC) with SMART Voltage and speed cutoff.

    Reviewed November 26, 2026 3 min read Level : Beginner DraftWritten by CoupeFab from the official documents cited. Technical review by Michaël Brassard pending.

    On this page
    1. What it does
    2. Torch height control (THC)
    3. Cutting workflow
    4. Common mistakes
    5. FAQ
    6. For Michaël to review
    7. Sources

    FireControl is the free control software for Langmuir Systems plasma tables (CrossFire, CrossFire PRO, CrossFire XR). It takes the G-code from CAM and drives the table and torch.

    What it does

    FeatureUse
    Load G-code, scale, rotateAdjust without going back to CAM
    Dry runCheck the path with no arc
    Run from hereRestart after an arc loss
    Override pierce delayAdjust without reposting
    Simple manual nestingDuplicate a part on the sheet
    Height control (with THC module)Keep a constant standoff while cutting

    Torch height control (THC)

    • SMART Voltage: the target voltage is sampled at the start of each cut rather than set by hand.
    • Torch Speed Cutoff: THC is disabled when speed drops below a threshold (corners, small holes) to avoid diving.
    • H0 / H1 codes in G-code to disable or re-enable THC on part of a path.
    • Voltage range 0 to 300 V.

    Caution

    THC only works with Langmuir’s post processors for Fusion and SheetCam, which insert the right codes. A generic post produces a program without height control.

    Cutting workflow

    1. In CAM, use the Langmuir post (Fusion or SheetCam) and your source’s cut chart parameters.
    2. Open the file in FireControl; check size and position.
    3. Set the origin (sheet corner); check the part fits the area.
    4. Dry run at a safe height.
    5. Cut; watch the arc and voltage.
    6. On arc loss: fix the cause (consumables, ground), then run from here.

    Common mistakes

    MistakeFix
    THC inactiveLangmuir post, THC module connected, THC settings enabled
    Diving in cornersSet Torch Speed Cutoff
    Parts offsetOrigin misplaced, or sheet moved
    Poor finishSee Plasma troubleshooting

    FAQ

    Does FireControl work with other tables?

    It is designed for Langmuir tables and their electronics.
