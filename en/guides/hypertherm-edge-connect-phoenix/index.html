    Hypertherm EDGE Connect and Phoenix controls: an operator’s first steps

    EDGE Connect, EDGE Pro, MicroEDGE Pro and Phoenix software: loading a part, nesting, CutPro Wizard, cut processes and charts, height control, True Hole, and where to find the right documentation.

    Reviewed November 26, 2026 3 min read Level : Intermediate DraftWritten by CoupeFab from the official documents cited. Technical review by Michaël Brassard pending.

    Many industrial plasma tables (and some oxyfuel and waterjet tables) run a Hypertherm control: the older EDGE Pro / MicroEDGE Pro / EDGE Pro Ti and the current EDGE Connect platform. All run Phoenix software. Per Hypertherm, EDGE Connect uses EtherCAT for motion and cutting control, runs Windows 10 Enterprise and comes as EDGE Connect (embedded CNC) and EDGE Connect TC (with touchscreen and hardware operator console).

    What the operator does in Phoenix

    TaskWhereRemember
    Load a partMain screen: shape library, file, download from host, DXF importProNest programs arrive ready to cut; see ProNest
    Arrange partsRepeat (straight, staggered, nested), alignment (Align Wizard), manual or automatic nestingAutomatic nesting depends on installed options
    CutCutPro Wizard (step-by-step) or manual modeHypertherm presents it as the fastest path for a new operator
    Processes and chartsProcess and Cut Chart screensFactory or custom charts, called from the program or the wizard
    Pause / resumePause, back up along the path, recover after arc lossCheck the exact procedure for your version
    Manual motionSoft OpCon (software console) or hardware consoleHome axes at startup

    Typical workflow for a sheet

    1. Power up and home the axes.
    2. Load the plate, check squareness; use the Align Wizard if it sits crooked.
    3. Load the program (or nest); check the preview.
    4. Run the CutPro Wizard: process, material, thickness and current per the charts; the wizard shows the consumables to install.
    5. Check consumables, gas and height; start.
    6. Watch the first pierce and the first part.

    Height control and hole quality

    • Height control (ArcGlide, Sensor THC or integrated, depending on the install) follows the charts’ arc voltage; see THC hunting and diving.
    • True Hole (depending on plasma system and options) improves holes in mild steel by combining consumables, charts and motion; it requires the conditions Hypertherm describes (material, diameter, thickness).
    • The Phoenix documentation has “cut quality issues” and “bevel cutting tips” sections: read them before calling service.

    Shift checklist

    • Axes homed
    • Consumables match what the wizard asks for
    • Gas pressure and flow (gas test)
    • Plate aligned, program checked in preview
    • Custom chart backup up to date

    Common mistakes

    MistakeFix
    Editing a factory chart without renaming itCreate a custom chart and save it
    Consumables different from the selected processFollow the CutPro Wizard prompt
    Plate not aligned, parts off the sheetAlign Wizard before cutting
    Not backing up machine settingsExport configuration files per the manual

    FAQ

    Where do I find the right manual?

    From Hypertherm’s documentation library, choosing your CNC (EDGE Connect, EDGE Pro…) and Phoenix version; installation manuals also include a section on operating Phoenix and the Soft OpCon.

    Can I send a Fusion or SheetCam program to a Phoenix control?

    Yes if the post outputs a format Phoenix accepts (EIA/ESSI depending on configuration); always validate on a drop. See Fusion plasma: posts per table.
