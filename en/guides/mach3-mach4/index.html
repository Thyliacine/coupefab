    Mach3, Mach4 and MachPro: where the PC CNC control software stands

    Current status of Mach3 (no longer updated), Mach4 Hobby and Industrial (maintenance) and MachPro, the role of the motion controller, and what to check before upgrading an old Mach3 machine.

    Reviewed November 26, 2026 3 min read Level : Intermediate DraftWritten by CoupeFab from the official documents cited. Technical review by Michaël Brassard pending.

    On this page
    1. Version status (as of November 26, 2026)
    2. How it works

    4. Before touching a Mach3 machine

    6. For Michaël to review

    The Mach family has long driven plasma tables, routers and converted mills from a Windows PC. Many used machines still run Mach3: knowing where the product stands helps decide whether to keep, migrate or change controls.

    Version status (as of November 26, 2026)

    ProductStatus
    Mach3No longer updated
    Mach4 Hobby / IndustrialLegacy products in maintenance mode
    MachProThe publisher’s new product, now MachLabs

    See mach-labs.com for current licences and compatibility.

    How it works

    Mach interprets G-code and sends moves to an external motion controller (Ethernet SmoothStepper, maker boards, etc.) that generates motor pulses. Mach3’s original parallel port has practically vanished from modern PCs.

    Caution

    The motion controller’s plugin must be compatible with the exact Mach version. Check the controller maker’s list before any upgrade.

    Keep, migrate or replace

    SituationOption
    Working Mach3 machine, stable PCKeep; back up the profile (XML), macros and licence
    Need new features, recent hardwareEvaluate MachPro with your controller
    Plasma with height controlCheck THC compatibility (plugin, screen) before changing
    Want open sourceLinuxCNC
    Small router or laserA grbl/grblHAL board with UGS

    Before touching a Mach3 machine

    • Copy the whole Mach3 folder (profiles, macros, screens, licence)
    • Note the motion controller, its plugin and settings
    • Note motor settings (steps per unit, velocity, acceleration) and inputs/outputs
    • Keep the CAM post used (SheetCam, Fusion…) — see Post processors

    FAQ

    Can I install Mach3 on Windows 11?

    Mach3 dates from a much older Windows era and is no longer updated; compatibility depends mostly on the motion controller and its plugin. Test before replacing a PC that works.
