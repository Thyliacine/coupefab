    SOLIDWORKS sheet metal: bend parameters, flat pattern and a clean DXF for cutting

    Base flange, K-factor, bend table or deduction, flat pattern, then DXF/DWG export of the flat pattern with bend lines on their own layer: the workflow to send a file that cuts right the first time.

    Reviewed November 26, 2026 3 min read Level : Intermediate DraftWritten by CoupeFab from the official documents cited. Technical review by Michaël Brassard pending.

    On this page

    2. 2. Model for manufacturing

    A SOLIDWORKS flat pattern is only right if the bend parameters match the shop that will bend it. A DXF is only useful if it holds the right geometry, on the right layers, at 1:1 scale.

    1. Sheet metal parameters

    In the Base Flange/Tab feature, or in the Sheet-Metal feature parameters:

    ParameterWhat to enter
    ThicknessThe real thickness (gauge converted to mm or in)
    Bend radiusThe inside radius the shop’s tooling produces
    Bend allowanceK-factor, bend table, allowance or deduction value
    Auto reliefRectangular, obround or tear depending on the part

    Shop tip

    Ask your bender for their K-factor or deduction table for the material, thickness and V-opening used. A generic K-factor gives an approximate flat. See Bend allowance and K-factor.

    Sheet metal gauge tables link thickness, radius and K-factor per material so the whole office uses the same values.

    2. Model for manufacturing

    • Constant-radius bends, no holes too close to a bend line (rules in Bend allowance and Press brake).
    • Native sheet metal features (Edge Flange, Hem, Sketched Bend) rather than converted solids.
    • Check the part flattens without error (Flatten).

    3. Export the flat pattern to DXF/DWG

    1. In the FeatureManager tree, right-click Flat-Pattern → Export to DXF/DWG, or File → Save As → DXF.
    2. In the DXF/DWG Output PropertyManager, pick Sheet metal.
    3. Entities to export: Geometry, and Bend lines if the bender wants them. Clear Bend lines for a cut-only file.
    4. To separate up and down bends: Options → Custom Map SOLIDWORKS to DXF/DWG → Enable, then assign “Bend lines – up direction” and “– down direction” to separate layers.
    5. Check the preview, save.

    Caution

    Since SOLIDWORKS 2022, bend lines no longer go to a BEND layer by default: without mapping, they may land mixed with geometry. Cutting software may then cut them. Create a map file and reuse it.

    4. Check the DXF before sending

    • Units and 1:1 scale (measure a known dimension)
    • Closed contours, no duplicates
    • Bend lines on their own layer (or absent)
    • No dimensions, title block or text in the cut file
    • Etching on a separate layer

    See DXF best practices.

    Common mistakes

    MistakeConsequence
    Default K-factorBent part out of tolerance
    Modelled radius ≠ shop radiusWrong flange lengths
    Unmapped bend linesCut by mistake
    Exporting a scaled drawing viewDXF not 1:1

    FAQ

    Do I need a drawing to export the flat?

    No. Direct export from the part is enough for cutting. A drawing remains useful for bending (angles, direction, dimensions) — see SOLIDWORKS drawings and CAM.
