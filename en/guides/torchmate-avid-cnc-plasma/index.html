    Torchmate and Avid CNC plasma tables: software, posts and height control

    Torchmate (Accumove, VMD, Torchmate CNC 4) and Avid CNC (Mach4 + SheetCam): which software chain, which post, how to allow or inhibit THC per operation and tune anti-dive.

    Reviewed November 26, 2026 3 min read Level : Beginner DraftWritten by CoupeFab from the official documents cited. Technical review by Michaël Brassard pending.

    Torchmate (Lincoln Electric Cutting Systems) and Avid CNC are two plasma table brands common in small North American shops. What they share: a three-program chain — CAD (drawing/DXF), CAM (toolpaths and G-code) and control (motion and height control).

    The software chains

    BrandCADCAMControl
    Avid CNCAny software that exports DXF (Avid mentions VCarve Pro)SheetCam with Avid’s post and toolsetsMach4 (motion and THC)
    Torchmate (by generation)Torchmate CAD or any DXFTorchmate CAD, SheetCam or Fusion depending on the postVisual Machine Designer (VMD) for Accumove 2 and 3; Torchmate CNC 4.x for USB 501A signal generators

    Caution

    Torchmate warns on its download page that installing the wrong control software version can damage the signal generator’s firmware. Check your model and contact tech support before any upgrade.

    Avid CNC: THC per operation in SheetCam

    Avid explains that SheetCam can write cut speed, target arc voltage and codes to allow or inhibit THC into the G-code:

    NeedOperation code snippetPath rules
    THC wantedM62P4 (THC allowed)Default rules, enabled
    THC not wantedM63P4 (THC inhibited)None

    Path rules automatically inhibit THC on some geometry (small holes, corners) where arc voltage rises as the machine slows.

    Avid CNC: THC settings in Mach4

    • Material profile (FLAT, MODERATE, SEVERE): sets THC speed and anti-dive; Avid recommends FLAT unless the sheet is badly warped.
    • Up / down sensitivity: 100 = precalculated values; change only if the profile isn’t enough.
    • THC log: records voltage while cutting; you can mark the log at a problem spot for diagnosis.

    Avid points out that arc voltage is an indirect height measurement: it climbs at lead-ins/outs, tight corners, small holes and over voids (already-cut parts). Without anti-dive, the THC responds by driving the torch down. See THC hunting and diving.

    Torchmate: what to remember

    • Identify the control generation (Accumove 2, 3 or newer; USB 501A signal generator) before choosing software and post.
    • VMD offers a basic shape library and part arrays without CAD.
    • In Fusion, the library includes a Torchmate 3.0 Mill/Plasma post; other controls need specific torch M-codes: validate with Torchmate (see Fusion plasma: posts per table).

    Commissioning checklist

    • Exact control and software version written down
    • Manufacturer’s post installed in CAM
    • Plasma tools built from the plasma source’s chart (see Reading cut charts)
    • THC allowed/inhibited per operation; anti-dive on
    • Test cut, THC log kept if there’s a problem

    Common mistakes

    MistakeFix
    Generic post instead of the brand’s postInstall the official post
    THC active on small holesPath rules or M63P4 on the operation
    Software upgrade without checking compatibilityContact Torchmate support first
    SEVERE profile by defaultGo back to FLAT, then adjust

    FAQ

    Can I use Fusion with an Avid?

    Avid mainly documents SheetCam; a Fusion post compatible with Mach4 plasma can work, but Avid’s THC codes must be reproduced. SheetCam is the documented path.

    My displayed arc voltage doesn’t match the chart: is that bad?

    The reading varies with consumables and machine; start from the chart, then adjust the target to the quality you see.
